Understanding SVD Compression

A = UΣVT

Singular Value Decomposition represents a matrix as three matrices. By retaining only the largest k singular values, we can construct an approximation of the original image while reducing the amount of information required to represent it.

How SVD Compression Works

An image can be represented as a matrix. SVD decomposes that matrix into three components, allowing us to approximate the original image using fewer singular values.

A ≈ Uk Σk VkT
